# Image Checker

A small single-page tool for checking how an image looks in light mode and dark mode, side by side.

## What it does

- Toggle the page itself between light and dark mode using the button in the top right.
- Upload an image (click the upload area or drag and drop a file onto it).
- Once uploaded, the image is shown in two panels at the same time — one on a light background, one on a dark background — so you can compare both without switching themes back and forth.
- Click "Remove image" to clear it and upload a different one.

Your theme choice is saved in the browser, so the page opens in the same mode next time.

## How to use it

1. Open `index.html` in any modern web browser (double-click the file, or drag it into a browser window).
2. No installation, server, or internet connection required — everything runs locally in the browser.

## Notes

- Images are processed entirely in your browser. Nothing is uploaded anywhere or stored outside your local session.
- Works with any standard image format (PNG, JPG, GIF, WebP, SVG, etc).
- Built as a single HTML file with no external dependencies, so it's easy to move, rename, or share.
